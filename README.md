# Sims4 Yootz Story

This is a major WIP, but my plan is to make this repo a story that is loosely based on my sims 4 Yootz playthrough (that's in another repo). 

However that plan will take **a lot** of time, so for now it's a super early very rough first draft in progress that's messy a full of notes that say things like "go back and change this because I need it to work differently now" which might be jarring for some readers, but is a normal part of the story crafting & development process. 
## How To Read This Story

This story is now broken up into parts. Above this part, click on the folder for the part you're on and then click on the md file whatever chapter ("##-ChapterName.md") you'd like to read. Github will open the markdown file as a rendered preview (so with all the images & text together) for you. Or you can download the whole project & open it in your favorite markdown software (mine is obsidian). Your choice. 

In the root of this repo (so in the same folder as this readme) is an idex.md file. It contains spoilers, because it include my titles for the parts. z-Merged is generated by a batch file, and is simply all the files dumped into one.
